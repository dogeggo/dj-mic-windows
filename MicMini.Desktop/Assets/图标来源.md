# Windows 图标来源

程序使用已分析的 DJI Mimo APK 内原有图标，没有 AI 生成或重新绘制图案。

来源 APK：`1790237230756-DJI-Mimo-store-official-release-10001997_sec.apk`。

APK SHA-256：`877cce18fb21cbdb6e025965e7eab4b06d823675428f61b14f641b719454c2a2`。

证据链：

1. `analysis/extracted/resources-decoded/AndroidManifest.xml` 第 174 行的 `application` 声明 `android:icon="@mipmap/ic_launcher_new"`、`android:roundIcon="@drawable/ic_launcher_round"`。
2. `mipmap-anydpi/ic_launcher_new.xml` 引用 `@mipmap/ic_launcher_background` 与 `@mipmap/ic_launcher_foreground`，对应官方黑色光圈背景与白色 DJI 标志。
3. Windows 使用 Manifest 明确引用的圆形版本：`res/drawable-xxxhdpi/ic_launcher_round.png`，原图为 384 × 384。该解码资源与 APK 条目 `res/kQ-.png` 的完整文件字节及 SHA-256 相同。
4. 原图 SHA-256 为 `7d09f3e553695c8be9ab0046777c2e9406f0d83443279ac42bc69ebaae1dbf73`；`dji-mimo-official-round.png` 保留这些原始字节，供侧栏使用。
5. `dji-mimo.ico` 包含 16、20、24、32、40、48、64、96、128、256 像素十种尺寸。处理仅包括 RGBA 转换及 Lanczos 缩放，保留原图透明度，不裁切、不调色、不重绘。

`mipmap-xxxhdpi/ic_launcher.webp` 是 APK 中残留的 Android 默认绿色机器人图标，Manifest 没有将其设为应用图标，因此未采用。

`prepare-icon.py` 可从原 APK 重新提取和生成资产。它首先验证 APK 与图标条目的 SHA-256，再输出 PNG、ICO 和 `icon-provenance.json`；后者记录二进制 Manifest、输入图像、输出图标的哈希与工具版本。

工程通过 `ApplicationIcon` 将 ICO 写入 EXE 原生图标资源，并通过 WPF `Resource` 和窗口 `Icon` 使用相同图标，覆盖窗口及任务栏显示。侧栏直接使用官方 PNG 原图。
