# Mic Mini Desktop 0.3.1

面向 Windows 11 的 DJI Mic USB 参数控制与电脑录音程序。已在当前 **DJI Mic Mini 2 接收端 + DJI Mic Mini 发射端**上验证，双方固件均为 `02.03.17.00`。型号名称来自设备返回信息。

0.3.0 更新：指示灯现显示为“开启/关闭”；程序、窗口与侧栏使用 APK 中提取的 DJI Mimo 官方图标；新增固件检查、文件校验窗口与升级流程实现。**当前 Mini 官方固件发现入口仍未确认，尚无可验证的匹配固件，实际安装暂不可用。** 尚未达到安卓版全部功能复刻。

0.3.1 更新：发射端电量以进度条显示，旁边保留电量等级与充电状态；新增右下角系统托盘，悬停图标查看电量。

## 启动和使用

1. 保留发布目录内全部文件，双击 `MicMini.Desktop.exe`。ZIP 先完整解压。
2. 插入接收端，保持发射端连接。程序自动读取设备信息、能力、参数和音频输入；需要重连时点击“连接”或“刷新”。
3. 在“声音与控制”修改参数。只有收到成功响应并回读到请求之后的新状态，才报告成功；失败或超时显示“设置未确认”。
4. 点击“开始录音”和“停止录音”保存 WAV；“打开目录”查看录音。
5. 在“设备与诊断”导出设备快照，或打开“固件升级”。
6. 点击窗口“最小化”可收起到系统托盘，音频、电量更新及正在进行的录音继续运行。悬停 DJI 图标查看电量等级、充电状态及录音状态；双击恢复窗口，右键选择“打开控制台”或“退出程序”。若图标被 Windows 收起，在时钟旁的隐藏图标区域查看。窗口关闭按钮仍正常退出并保存录音。

需要 Windows 11 x64 与 .NET 10 Desktop Runtime。本机 Desktop Runtime 10.0.8 和 `USB\VID_2CA3&PID_4011&MI_06` 的 WinUSB 已准备好，**无需重复安装驱动**，日常使用无需管理员权限。其他电脑参考同目录《安装USB参数接口.md》。发布采用依赖运行时方式，不能只复制 EXE。

同一时刻只打开一个实例。研发测试前先关闭桌面程序，避免争用 USB 通道。

## 功能范围

| 功能 | 当前支持范围 |
| --- | --- |
| 连接与信息 | HID / WinUSB 发现、连接、断开、刷新；RX/TX 产品名、正式 SN、设备名、版本、连接状态；TX 电量进度条、等级与充电状态 |
| 接收端声音参数 | 单声道/立体声、安全音轨、自动防爆音、接收端增益 |
| 接收端电源参数 | 超时自动关机、跟随相机开关机 |
| 发射端声音参数 | 降噪开关、两个降噪等级、低切 |
| 发射端其他参数 | 电源键开关降噪、超时自动关机、指示灯开启/关闭 |
| USB 音频 | 实时左右声道电平；48 kHz、双声道、PCM 16-bit WAV 录音 |
| 诊断 | 有界日志、设备身份/能力/参数 JSON 导出 |
| 固件管理 | 官方服务查询、本地容器校验、下载客户端与安装门槛；当前无适用于所连设备的已验证官方候选 |

接收端增益由能力返回，当前为 `-12、-6、0、+6、+12 dB`。录音保存在 `%LOCALAPPDATA%\MicMiniDesktop\Recordings`，诊断保存在同级 `Diagnostics`。未点击录音时仅采集电平；关闭窗口会完成录音文件头。断开设备调参不影响独立的 USB 音频采集。

## 固件功能的实际状态

进入“设备与诊断 → 固件升级”，选择接收端或发射端后检查官方更新。已恢复的官方通用服务可完成接口发现、版本列表、配置及下载地址解析；下载校验大小和 MD5，并计算 SHA-256。当前 `dm300` / `dm202b` 返回状态 2、无匹配记录；尚不能证明这是 Mini 实际使用的在线发现入口。**这不代表设备已是最新版本。** Mic 3 的成功响应仅验证通用格式，不作为 Mini 固件。

本地文件必须通过结构、CRC、双 MD5、型号、模块与版本检查，还须匹配本次官方清单的文件摘要才能安装。CRC/MD5 不是数字签名；没有可核验的官方来源，选择文件不会解锁安装。未知编码、布局被拒绝。

升级代码已实现独占 HID 通道、进入升级、分包、流控、超时、断线处理和重连后身份及实际版本核验。仅收到设备接受结果不报告成功。确认后整个预检和安装阶段禁止关闭，写入前通过新连接读取完整身份。失败不自动重刷、不自动降级；尚无验证过的断点续传或回滚。

**本次没有进入设备升级模式，没有刷写固件，也没有完成真实升级成功验证。** 解析与传输测试主要用合成文件和替身通道，不能代替真实官方包与硬件验证。下载与操作记录位于 `%LOCALAPPDATA%\MicMiniDesktop\Firmware`。

## 使用边界

- **指示灯**：用户切换模式 2 后明确观察到关闭；结合原状态亮灯，现标注 raw0＝开启、raw2＝关闭。软件更新不会主动修改这一设置。
- **安全音轨**：启用会自动切换单声道；关闭后不会自动恢复原声道，需要自行选择。
- **降噪等级**：0/1 均能修改并回读，仍显示“等级 1/等级 2”，与安卓“弱/强”的对应未确证。
- **TX 增益与电量**：当前 TX 未声明可调增益，试写无状态变化，因此不提供控件。电量使用进度条和等级文字显示，长度按设备原始值 0–7 绘制；满电对应等级未确认，不换算为百分比。悬停可查看说明，未读取时显示灰色条和“未读取”，不当作零电量。
- **连接范围**：只实测一台 RX 和一台 TX。固件入口不猜测多 TX 的 HID 地址；其他型号与多 TX 未验证。
- **其他未完成项**：BLE 直连、扬声器监听、32-bit float 电脑录音。电脑录音不是 TX 内录；未将 Mic 3 的内录、时间码、素材下载、群组功能套用到 Mini。标准 WAV 约 4 GiB 时结束录音并报告限制。
- 图标取自用户提供 APK 的 DJI Mimo 官方资源；本程序不是 DJI 官方发布的 Windows 应用。

## 编译与验证

安装 .NET 10 SDK，在源码 `desktop` 目录执行：

```powershell
.\build.ps1 -Test
```

先离线检查，再发布至 `dist/MicMiniDesktop/`；运行前关闭旧程序避免文件占用。离线检查不连接麦克风、不录音、不改变设备参数；窗口测试会短暂创建测试窗口。`tests/` 覆盖基础协议、音频、能力、状态回放、通信会话和固件协议/容器/传输/目录/窗口保护。硬件测试单独保留，未加入默认构建，部分会修改参数或录音。精确验证计数见发布目录《Mic桌面端0.3.0更新说明.md》及源码 `../docs/` 对应文件。

使用 .NET 与 Windows 系统 API，无第三方 NuGet 运行时依赖。音频经 WinMM 采集、独立线程和有界队列写盘；WinUSB 使用可取消异步 I/O，参数操作串行，超时不自动重发。
